# Cologuri Admin Portal (কোলোগুড়ি অ্যাডমিন প্যানেল)

গ্রুপ অ্যাডমিন (ট্যুর অপারেটর) ও সুপার অ্যাডমিনদের জন্য তৈরি সেন্ট্রাল ম্যানেজমেন্ট পোর্টাল।

## প্রযুক্তি স্ট্যাক (Tech Stack)
- **ফ্রন্টএন্ড ফ্রেমওয়ার্ক**: React 19 + Vite
- **স্টাইলিং**: Tailwind CSS v4 + কাস্টম বাংলা টাইপোগ্রাফি
- **স্টেট ম্যানেজমেন্ট**: Zustand
- **রিয়েল-টাইম মনিটরিং**: Socket.io-client
- **আইকন**: Lucide React + Material Symbols

## পোর্টাল ও ফিচারসমূহ (Key Features)

### ১. গ্রুপ অ্যাডমিন ড্যাশবোর্ড (`/group-admin`)
- **ট্যুর ও সিট ম্যানেজমেন্ট**: নতুন ট্যুর তৈরি, প্রাইসিং, পিকআপ পয়েন্ট এবং লাইভ সিট বুকিং ট্র্যাকিং।
- **জয়েন্ট ট্যুর নেটওয়ার্ক**: অন্যান্য ট্যুর গ্রুপের সাথে সিট শেয়ারিং ও কোলাবরেশন।
- **আয় ও ওয়ালেট**: মোট উপার্জন, পেন্ডিং সেটেলমেন্ট এবং কমিশন মনিটরিং।

### ২. সুপার অ্যাডমিন ড্যাশবোর্ড (`/super-admin`)
- **এজেন্সি ভেরিফিকেশন (KYC)**: ট্রেড লাইসেন্স ও এনআইডি ভেরিফিকেশন ম্যানেজমেন্ট।
- **প্ল্যাটফর্ম মেট্রিক্স ও অ্যানালিটিক্স**: মোট বুকিং ভলিউম, রাজস্ব এবং সক্রিয় পর্যটক সংখ্যা।
- **ডিসপিউট ও কমপ্লায়েন্স**: গ্রাহক অভিযোগ ও অডিট ম্যানেজমেন্ট।

## সেটআপ ও রান করার নিয়ম (Setup & Run)

```bash
# ১. ডিপেন্ডেন্সি ইনস্টল
npm install

# ২. এনভায়রনমেন্ট তৈরি
cp .env.example .env

# ৩. ডেভেলপমেন্ট সার্ভার চালু (Port 5174)
npm run dev

# ৪. প্রোডাকশন বিল্ড
npm run build
```
